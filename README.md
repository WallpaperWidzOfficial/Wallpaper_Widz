**Wallpaper Widz** is a modern Android wallpaper application built with Flutter. Designed with a sleek dark aesthetic, it delivers a smooth user experience with zero distractions and razor-sharp wallpapers optimized for any display.

---

## 🔥 Why Choose Wallpaper Widz?

- **✨ Premium Aesthetic:** Designed with an immersive dark theme, fluid visual feedback, and clean UI components.
- **🚫 100% Ad-Free Experience:** Zero annoying pop-ups or banner ads—pure, uninterrupted wallpaper browsing.
- **🖼️ 8K UHD Quality:** Hand-picked high-resolution imagery tailored specifically for AMOLED and high-density screens.
- **📱 Universal Compatibility:** Seamlessly scales and adapts to fit any smartphone screen size or aspect ratio.
- **🚀 Sleek Modern UI:** Clean interface with easy interactive previews and direct wallpaper application.

---

## ✨ Core Features

- **Wallpaper Preview:** Quickly check how wallpapers look on your screen before applying.
- **One-Tap Apply:** Easily set wallpapers to Home Screen, Lock Screen, or Both within seconds.
- **Curated 8K Categories:** Hand-picked collections including AMOLED, Space, Minimalist, Anime, Nature, etc.
- **Fast & Lightweight:** Smooth swiping experience with optimized network loading for high-res images.
